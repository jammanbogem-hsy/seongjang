# Contextual pixel cats

기존 레퍼런스의 흰색 픽셀 고양이를 바탕으로 웹앱의 상태와 행동을 보조하는 25개 에셋입니다.

- `cat-welcome.png`: 참여 환영
- `cat-autosave.png`: 자동저장 진행
- `cat-comment.png`: 댓글과 답글
- `cat-review.png`: 주최자 검토
- `cat-sync.png`: 화면 동기화
- `cat-focus.png`: 개인 작성 집중
- `cat-deadline.png`: 남은 시간과 마감
- `cat-empty.png`: 빈 상태
- `cat-saved.png`: 저장 완료
- `cat-celebrate.png`: 제출 완료
- `cat-reply.png`: 답장과 대화 연결
- `cat-reaction.png`: 청중 반응
- `cat-presenter.png`: 라이브 발표
- `cat-room-code.png`: 방 코드 입장
- `cat-invite.png`: 관리자 초대
- `cat-dashboard.png`: 결과 수합 대시보드
- `cat-export.png`: 행사 기록 내보내기
- `cat-curator.png`: 작품 전시 큐레이션
- `cat-search.png`: 참여자와 콘텐츠 검색
- `cat-security.png`: 관리자 인증과 보안
- `cat-teamwork.png`: 참여 기록 연결
- `cat-upload.png`: 작품 업로드
- `cat-pin-help.png`: 개인 입장코드 지원
- `cat-break.png`: 세션 종료와 휴식
- `cat-timer-start.png`: 타이머 시작

모든 파일은 같은 흰색·네이비·블루 픽셀 팔레트로 생성한 뒤 크로마키를 제거한 RGBA PNG입니다. 동일 이름의 640px WebP는 실제 앱에서 사용하는 경량 배포본입니다. 고양이는 Material Symbols나 버튼 아이콘을 대체하지 않고 안내, 빈 상태, 보조 삽화로만 사용합니다.
