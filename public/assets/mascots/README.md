# Contextual pixel cats

기존 레퍼런스의 흰색 픽셀 고양이를 바탕으로 웹앱의 상태와 행동을 보조하는 10개 PNG 에셋입니다.

- `cat-welcome.png`: 참여 환영
- `cat-autosave.png`: 자동저장 진행
- `cat-comment.png`: 댓글과 답글
- `cat-review.png`: 주최자 검토
- `cat-sync.png`: 화면 동기화
- `cat-focus.png`: 개인 작성 집중
- `cat-deadline.png`: 남은 시간과 마감
- `cat-empty.png`: 빈 상태
- `cat-saved.png`: 저장 완료
- `cat-celebrate.png`: 제출 완료

모든 파일은 같은 흰색·네이비·블루 픽셀 팔레트로 생성한 뒤 크로마키를 제거한 RGBA PNG입니다. 고양이는 Material Symbols나 버튼 아이콘을 대체하지 않고 안내, 빈 상태, 보조 삽화로만 사용합니다.
